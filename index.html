Description & Data Coverage

Comprehensive telemetry dataset from millions of active vehicle listings and confirmed transactions across OLX Autos platform throughout Indonesia.

  • Updated every 5-15 minutes directly from secondary market transaction streams.
  • Includes model parameters, manufacture year, transmission, odometer mileage, and depreciation index.
  • Use timestamp or date_time parameters to fetch market snapshots at specific time ranges.

Query Parameters

Parameter Type Description
date_time string (ISO 8601) YYYY-MM-DD[T]HH:mm:ss (WIB / UTC+7)
region_id string (optional) BPS city/province code (e.g., 3171 for South Jakarta)
limit integer Number of items per response page (default: 50, max: 500)
